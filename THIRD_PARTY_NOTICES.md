## sing-box

- Upstream: <https://github.com/SagerNet/sing-box>
- Default release source: `v1.14.0`, commit `0b8995879f29a9b98ee027bc17b75e101445b238`.
- Copyright (C) 2022 by nekohasekai and upstream contributors.
- License: GNU GPL version 3 or later, with the upstream naming/association
  notice preserved in [licenses/sing-box-LICENSE.txt](licenses/sing-box-LICENSE.txt).

Release builds compile sing-box as a separate executable and embed its
compressed bytes. It runs as a child process; the sing-box Go library is not
linked into Karing TUI. Release archives contain the upstream license and
`BUILD-INFO.txt`, identifying the exact source commit and build options.
The same release supplies `sing-box-<version>-source.tar.gz` from that commit.

When `SING_BOX_VERSION` is overridden, the package's `BUILD-INFO.txt` and its
bundled sing-box license describe the actual core being distributed.

## Karing and rule-set data

- Karing: <https://github.com/KaringX/karing>
- Reference/resource snapshot: `0efd3eae75770dd9f40df4a1dd6f0dbe0bc78f8b`.
- Copyright (C) 2024 by nebula and upstream contributors.
- Upstream license, including its naming/association notice:
  [licenses/karing-LICENSE.txt](licenses/karing-LICENSE.txt).

The `.srs` snapshots under `internal/catalog/data/rulesets/` are copied from
Karing's `assets/datas/`. The initial built-in rule sets under
`internal/rules/data/embedded/` use the corresponding geosite/geoip data.
The original data sources and update endpoints include:

| Data | Upstream |
| --- | --- |
| geosite / geoip | <https://github.com/MetaCubeX/meta-rules-dat>, `sing` branch |
| ACL4SSR in sing-box format | <https://github.com/KaringX/karing-ruleset>, `sing` branch |
| ACL4SSR original rules | <https://github.com/ACL4SSR/ACL4SSR> |

Classification lists are generated by `scripts/gen-catalog.sh`; binary
snapshots can be refreshed with `scripts/sync-builtin-rulesets.sh`. Rule data
retain the notices and terms of their respective upstream sources. Karing TUI
does not claim authorship of these data sets.
